# Week 06 Evidence

offline_comparison.json is generated by:

    python -m week06.run_acceptance

The normal main-flow case is different: course rules require a real Gemini request. Run:

    python -m week06.live_chaining

with private GEMINI_API_KEY and GEMINI_MODEL. The runner writes a sanitized W06-LIVE-*.json file with LIVE_NOT_RUN, LIVE_FAIL, or LIVE_PASS.

Never commit the API key or .env.
