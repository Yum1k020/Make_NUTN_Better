## 網站採用的 113 規則摘要

- 最低畢業學分：134 學分。
- 通識課程：28 學分，其中校核心必修 10 學分、領域／多元選修 18 學分，四大領域至少修習三個領域。
- 院核心必修：4 學分。
- 系專業必選修：至少 82 學分，其中專業必修 70 學分、專業選修至少 12 學分。
- 自由選修：至少 20 學分，通識課程不認列。
- 學術講座：10 場，並撰寫心得報告。
- 專業領域學程：三個學程中至少取得兩個學程證書；每個學程須通過三門規劃課程。

本專案提供的是課堂展示與規劃輔助，不取代校方正式課務、抵免或畢業資格審核。
