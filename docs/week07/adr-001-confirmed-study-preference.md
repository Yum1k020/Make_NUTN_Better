# ADR-001：採用已確認的學習時段偏好記憶

- 狀態：Accepted
- 日期：2026-10-28
- Baseline：`2b47fb4`
- Candidate：`4d83d26`
- 路線：A「保存一個已確認欄位」

## 問題

「智慧學習」原版每次進入都使用固定時段，無法沿用使用者已反覆設定的長期學習偏好。若直接保存整段規劃請求，又會把考試日期、私人行程或一次性的可用時段誤當成永久記憶。

## 決策

只保存一個型別化欄位 `preferredStudyPeriod`。使用者必須按下「確認並保存」才會寫入；新 session 進入智慧學習頁時，系統透過受控 API 讀回目前有效版本並預選時段。記憶 30 天到期，可更正與撤回。

每次寫入驗證：

1. 示範使用者身分存在。
2. 請求符合固定 schema 且 `confirmed` 為 `true`。
3. `expectedVersion` 等於目前版本。
4. `operationId` 未被其他內容使用；完全相同的重送只回放原結果。

偏好只影響 UI 的預選值。原本的規則排程、衝突 Gate、私人行程檢查與 Agent 說明都保留，記憶不能代替目前資料或使用者對本次規劃的選擇。

## 儲存選擇

使用伺服器端 JSON 檔與原子檔案替換，因為本週只需單機原型的一個欄位，而且要讓新瀏覽器 session 透過工具讀回。實際資料檔由 Git 忽略。

## 替代方案

| 方案                       | 未採用理由                                                               |
| -------------------------- | ------------------------------------------------------------------------ |
| 只用瀏覽器 `localStorage`  | 缺少受控後端 schema、版本衝突、跨 user 隔離與冪等寫入證據。              |
| 保存完整規劃請求或對話摘要 | 會擴大個資與暫時條件的保存範圍，也難以判斷哪個值仍有效。                 |
| SQLite／正式資料庫         | 對單一欄位課堂增量過重；多實例或正式部署時再採用。                       |
| 向量資料庫                 | 本題是精確欄位查詢，不需要語意相似度。                                   |
| 事件流作為主要讀取模型     | 本週只需目前有效偏好；operation 紀錄僅支援冪等與證據，不開放給模型檢索。 |

## 後果與代價

優點：

- 新 session 可重用已確認偏好，減少重複設定。
- 目前值、來源、owner、版本、期限與狀態可直接驗收。
- 更正、撤回、過期、跨 user 與重送都有確定性測試。
- 記憶服務失敗不會阻止原本的手動設定與規則排程。

代價：

- JSON 檔只適合單機，正式多實例部署需要資料庫交易。
- 示範 header 不是正式身分驗證，正式部署前不可直接沿用。
- 撤回保留本機 operation 證據；完整刪除需要額外的保留與備份政策。
- 增加一個 API、資料契約、UI 狀態與測試維護面。

## 隱私與失敗邊界

- 不保存私人行程、考試日期、prompt、API key 或模型內部推理。
- 記憶內容不傳給 OpenAI；Agent 仍只接收原規劃請求需要的資料。
- 損壞的記憶檔會停止讀取，不會默默重建並覆蓋原資料。
- 過期或撤回記憶不回填 UI；舊版本寫入會回報衝突，要求重新讀取。
- 實際記憶檔與 `.env.local` 均不提交 Git。

## 驗收

採用條件是：原主流程不回歸；新 session、更正、撤回、到期、跨 user、未授權與重送案例通過；瀏覽器 UI 能顯示實際工具結果與版本。驗收結果與 run ID 記錄於本目錄的 `README.md`。
