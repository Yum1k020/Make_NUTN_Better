# ADR-001：採用已確認的每次複習分鐘數記憶

- 狀態：Accepted
- 日期：2026-10-28
- 路線：A「保存一個已確認欄位」

## 問題

「智慧學習」在新 session 需重新設定每次複習時長。若保存整段規劃請求，又會將考試日期、私人行程與當次限定誤當成長期記憶。

## 決策

只保存型別化欄位 `study_session_minutes`，值必須是 15–240 的整數分鐘。使用者必須按下「確認並保存」才會寫入；新 session 在本輪沒有明確值時，才讀回目前有效版本。記憶預設 30 天到期，可更正與撤回。

每次寫入驗證：

1. 示範使用者身分存在且與 owner 一致。
2. 請求符合固定 schema 且 `confirmed` 為 `true`。
3. `expectedVersion` 等於目前版本。
4. `operationId` 未被其他內容使用；內容完全相同的重送只回放原結果。

讀回偏好只會預選「每次安排時長」。規則排程、衝突 Gate、私人行程檢查與使用者本次選擇仍保留，記憶不能取代當前資料。

## 儲存選擇

Python 驗收 runner 與 React 網站原型都使用伺服器端 JSON 檔與原子檔案替換，因為本週只驗收單機原型的一個欄位。實際資料檔均由 Git 忽略。兩個入口使用同一欄位與生命週期契約，但不共用同一實體 JSON 檔。

## 替代方案

| 方案 | 未採用理由 |
| --- | --- |
| 只用瀏覽器 `localStorage` | 缺少受控後端 schema、版本衝突、跨 user 隔離與冪等寫入證據。 |
| 保存完整規劃請求或對話摘要 | 擴大個資與暫時條件的保存範圍。 |
| SQLite 或正式資料庫 | 對單一欄位課堂原型過重；多實例或正式部署時再採用。 |
| 向量資料庫 | 本題是精確欄位查詢，不需要語意相似度。 |

## 後果與代價

優點：

- 新 session 可重用已確認的每次複習時長。
- 目前值、來源、owner、版本、期限與狀態可直接驗收。
- 更正、撤回、過期、跨 user 與重送都有確定性測試。
- 記憶服務失敗不會阻止原本的手動設定與規則排程。

代價：

- JSON 檔只適合單機，正式多實例部署需要資料庫交易。
- 示範 header 不是正式身分驗證，正式部署前不可直接沿用。
- 撤回保留本機 operation 證據；完整刪除需要額外保留與備份政策。

## 隱私與失敗邊界

- 不保存私人行程、考試日期、prompt、API key 或模型內部推理。
- 網站記憶內容不傳給 OpenAI；Agent 仍只接收原規劃請求必要資料。
- 損壞的記憶檔會停止讀取，不會默默重建並覆蓋原資料。
- 過期或撤回記憶不回填 UI；舊版本寫入會回報衝突。

## 驗收

採用條件是：原主流程不回歸；新 session、更正、撤回、到期、跨 user、未授權與重送案例通過；瀏覽器 UI 能顯示實際工具結果、值、版本與到期日。
