# Week 07 架構決策總覽

## 決策一：智慧學習保存一筆已確認的複習分鐘數

狀態：ADOPT_OFFLINE。live 狀態須依當次執行證據判定。

只保存 `study_session_minutes`，值為 15–240 分鐘整數。使用者必須明確確認；本輪明確輸入優先於記憶。每筆資料包含 owner、source、version、expiry、狀態與 operation ID。跨 user、過期、撤回、舊版本及未確認寫入都不放行。

未採用完整對話記憶、向量資料庫或整份規劃請求，因為它們會擴大個資與暫時條件的保存範圍。JSON 只適合單機課堂原型；正式多實例環境需要資料庫交易與正式身分驗證。

## 決策二：畢業說明採 300 秒 TTL 與來源重驗證

狀態：Conditional adoption for local prototype。真實 Gemini 與正式跨 user 驗收仍未完成。

衍生說明不是正式學籍資料。系統將說明限制在一個瀏覽器工作階段 scope，保存來源指紋、產生時間與到期時間；顯示前及生成後重新核對來源。來源更新、到期或重查失敗時立即停止使用說明。

未採長期資料表、跨裝置同步或向量檢索，因為本需求是限制衍生說明有效期，而不是建立長期個人化記憶。代價是每 15 秒多一次唯讀檢查，背景分頁仍可能受瀏覽器節流，且 scope 不能替代正式登入授權。

## 共同原則

- 明確區分正式資料、使用者偏好與模型衍生說明。
- 記憶不能取代目前資料、規則計算或使用者當次選擇。
- 撤回或到期停止後續使用，但完整實體刪除需另定備份與稽核政策。
- trace 與公開證據不得包含 API key、token、ADC JSON、真實個資或模型內部推理。
